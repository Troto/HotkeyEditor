Advanced Bind

Getting started

Hover to explore, click to rebind. Nothing touches your game — edits only change the file you Download; copy it back to apply.

Layout

Set the QWERTY / Dvorak switch to match the layout your file was made in — it converts the binds and relabels the keyboard.

Binding

Click a bound key on the on-screen keyboard — or a command's hotkey button in the command list — then press the new key. Turn on Advanced Bind for the full command list, search & filter, and unbinding.

How it works
AAttack1/2
  • Click an empty key — filters to that key's commands (click again to clear)
  • Click a bound key — arms the rebind, then press (or click) a new key
  • Drag onto an empty key — rebinds to that key (stacks rebind all commands)
  • Drag onto a bound key — swap the commands' binds
  • Stacked keys — click the badge to cycle which command is active when clicking to rebind. Dragging affects the whole stack.
  • Brighter keys have more commands bound to them (Shade keys toggle)
▾Group👁12
  • Hover a heading — previews the group's keys and icons
  • Click a heading — loads that group's commands onto the keyboard, ready to rebind (click again to clear)
Ctrl
  • Tap Ctrl/Shift, or click Ctrl/Alt/Shift, then press the key — arms a modifier and binds the key. Used to avoid browser shortcuts like Ctrl+N
  • Click anywhere else — cancels a rebind in progress
Advanced Bind — what it adds on top
Command
  • The full command list — every command as a row, searchable and filterable; icon-less commands live here rather than on a key
  • Hover a row — previews its key(s) on the keyboard
  • Click the name — selects it and lights its key
  • Click the hotkey — arms the rebind, then press the new key
  • Right-click the hotkey — unbinds it (only available in advanced bind mode)
A
  • Hover a key — highlights every command bound to it
▾Group👁12
  • Click 👁 / the count - same as normal
  • Click the name — collapse / expand the group
Conflicts
  • The Hotkey conflicts panel flags keys shared by more than one command — there are Confirmed conflicts, and Possible conflicts which may clash depending on context
  • Hover a conflict — previews the conflicting command
  • Click a conflict — filters the list to those conflicting commands
  • Hide Conflicts hides the panel and all conflict highlighting
