# SC2 data sources & provenance

The StarCraft II module's dataset is generated from two sources.

## 1. Extracted game files (primary) — `SC2 data/`

The default bindings, command-card layouts/positions, names and icons all come from StarCraft II's
own data, extracted from the game and vendored under `SC2 data/`:

- `HotkeyData/<mod>.sc2mod/…` — `unitdata.xml`, `buttondata.xml`, `gamehotkeys.txt` for the LotV
  multiplayer dependency chain (`core → liberty → libertymulti → swarm → swarmmulti → void →
  voidmulti`).
- `GameStrings/mods/<mod>.sc2mod/…/gamestrings.txt` — localized display names.
- `Icons/mods/<mod>.sc2mod/…/*.dds` — ability icon textures.
- `SC2 texture ability link.txt` — an SC2-editor export of display-name → icon (fallback map).

Generated by `gen_sc2_data.py` (→ `sc2.json`) and `gen_sc2_icons.py` (→ `sc2_icons.json` +
`icons/*.png`). The merge/hotkey-resolution process follows the approach of
**[BeedeBdoo/Sc2HotkeyData](https://github.com/BeedeBdoo/Sc2HotkeyData)** (validated against its
`Defaults.ini`).

StarCraft II is © Blizzard Entertainment; the extracted data is used here for a fan hotkey tool.

## 2. Melee (ladder) roster — jcfieldsdev (MIT)

The extracted game files contain far more than ladder units — co-op commanders, campaign heroes,
and engine-only SC1 remakes (Defiler, Scourge, Scout, the SC1 Queen `QueenMP`, …) that aren't
playable in normal matches. To restrict the editor to the melee roster we use the curated unit
list from:

**jcfieldsdev/starcraft2-hotkey-editor** — https://github.com/jcfieldsdev/starcraft2-hotkey-editor
(MIT License, © jsfields). Its `www/scripts/data.js` marks the true melee roster by `commander`
(the base races Terran/Protoss/Zerg vs co-op/campaign groups).

`gen_sc2_melee.js` reads that `data.js` and writes `sc2_melee.json` (melee unit display-names,
caster ids/qualifiers, and command output-names). `gen_sc2_data.py` uses it to set each unit's
`melee` flag: a unit is kept if jcfieldsdev lists it by name, by caster id (incl. add-ons like
`FactoryTechLab`), by owning a unit-specific melee command, or as a transform-state variant of a
melee unit (a lifted building's `Land`, etc.). Validated: 304 of jcfieldsdev's 327 melee commands
match the generated data; the remainder are jcfieldsdev quirks (its bogus "NovaStone" pseudo-unit,
folded generic attack variants) or the opposite morph-state's qualifier (both forms are valid
game command names — confirmed against a real `.SC2Hotkeys` file).

This is the same MIT-licensed source the Warcraft III module uses for its WC3 dataset (see
`../../Warcraft3/data/SOURCE.md`).
